This repo manages the F200 S/TEM instrument at the Molecular Foundry in building 72. In order to use the instrument, you must have an active user proposal, and be signed off to use the instrument by Foundry staff. 

In order to reserve time on the instrument, speak with Foundry staff. The instrument scheduling form is available [here](https://forms.gle/S1p85ZSjFULZ5ZRp8). Sessions must be booked before you can use the instrument, and users are responsible for booking any special holder they plan to use. Users may only book holders they are trained to use by NCEM staff.
