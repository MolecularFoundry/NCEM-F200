# NCEM F200 Github Page
This repository is used to manage the NCEM F200 Transmission Electron Microscope. Access to this repository is not a substitute for on the job training at the microscope, and all users need to ensure they are approved to work via the LBL WPC system before using the microscope. 
This repository documents all the user manuals for routine workflows at the F200, but these documents are always evolving, and possibly contain bugs. Please report any potential problems with manuals or with the microscope itself  using the Github "Issues" page on this repository.
