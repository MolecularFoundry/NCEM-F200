# NCEM F200 Software
The F200 has various pieces of software, which control different components of the microscope. Most of these are installed on their own PC, but communicate with each other over the network. Here is a brief description of some of the software. 

## JEOL TEM Center
This is the main software for controlling the TEM, turning on the beam, doing alignments, and checking the vacuum levels. You can also use this software to image the fluorescent screen.
