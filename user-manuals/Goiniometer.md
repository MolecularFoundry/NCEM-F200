# Goiniometer Operation

1. The stage can be moved using the track ball in X/Y. 
2. The stage can be moved in Coarse, Regular, and Super Fine mode. The range of motion is very limited in super fine mode. 
3. Tilting the stage via tilt X and tilt Y can be done in the TEM center software, or using the buttons on the hand panel. 
4. XYZ, TX, TY locations can be saved in the nanospace map using the "Memory" button. You can drive to a saved location using the "Shoot" button. If this feature is not working, you likley did not select the TEM holder you are using in the Open Project panel. 


To load and unload a TEM holder, refer to the respective protcols.
