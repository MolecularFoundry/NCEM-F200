# SA Diffraction
1. Set the spot to 1, angle to 3. 
2. Select the MAG button on the right hand panel.
3. Move a target sample to the center of the beam. 
4. Push the STD FOCUS button and focus sample with [z height](Z height.md).
5. Insert an appropriate SA aperture and center it. 
6. Select the DIFF button on the right hand panel. 
7. Set the appropriate camera length with the MAG/CAML knob. 
8. Turn the brightness knob fully clockwise. 
9. Insert a HC aperture and focus on the edge of the aperture using diffraction focus. 
10. The bragg spots should now be quite sharp, but if needed adjust the brightness knob to sharpen the diffraction pattern. 
11. Center the pattern with PLA selected using the DEF/STIG knobs.
